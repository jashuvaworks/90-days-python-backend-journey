# Day 1 — Python variables and data types

## Goal
Write and run a small Python program using variables, strings, integers, floats, booleans and input.

## ELI5
A variable is a name that refers to a value. Example: `name = "Sam"`.

## Example
```python
name = input("Enter your name: ")
age = int(input("Enter your age: "))
print("Hello", name)
print("Next year you will be", age + 1)
```

## Exercises
1. Create variables for a name, age and city; print them.
2. Store two numbers and print their sum, difference and product.
3. Ask for a name and greet the user.
4. Ask for two numbers and print their average.
5. Create one string, integer, float and boolean; print `type()` for each.

## Completion test
Without copying:
- explain what a variable is;
- explain `str`, `int`, `float`, `bool`;
- write a program that asks for a name and age;
- explain why `int(input(...))` converts the input.
