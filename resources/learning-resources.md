# Learning Resources — Use in this order

Do not collect courses endlessly. Use one main course and official documentation as reference.

## Python
- Main beginner course: https://cs50.harvard.edu/python/
- Official tutorial: https://docs.python.org/3/tutorial/
- Practice: https://exercism.org/tracks/python (optional practice, not a second course)

## SQL and PostgreSQL
- Beginner interactive SQL practice: https://sqlbolt.com/
- PostgreSQL official tutorial: https://www.postgresql.org/docs/current/tutorial.html
- PostgreSQL documentation: https://www.postgresql.org/docs/

## HTTP and FastAPI
- HTTP overview: https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview
- FastAPI official tutorial: https://fastapi.tiangolo.com/tutorial/
- Pydantic docs: https://docs.pydantic.dev/latest/

## Database tooling
- SQLAlchemy 2.0: https://docs.sqlalchemy.org/en/20/
- Alembic: https://alembic.sqlalchemy.org/en/latest/

## Testing and tools
- pytest: https://docs.pytest.org/en/stable/
- Git book: https://git-scm.com/book/en/v2
- GitHub Skills: https://skills.github.com/
- Docker getting started: https://docs.docker.com/get-started/

## Rules for using a resource
1. Watch/read only the relevant section for today's topic.
2. Stop after the concept is clear enough to practise.
3. Recreate examples from memory.
4. Use official docs to answer specific questions, not to read everything.
5. If stuck for 20–30 minutes, write the exact error and reduce the problem to a small example.
