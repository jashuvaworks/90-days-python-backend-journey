# Job Search System

## Target titles
- Python Developer Intern
- Backend Developer Intern
- Backend Developer Trainee
- Junior Python Developer
- Associate Software Engineer
- Graduate Software Engineer (check degree criteria)

## Search sources
- LinkedIn Jobs: https://www.linkedin.com/jobs/
- Naukri: https://www.naukri.com/
- Foundit: https://www.foundit.in/
- Wellfound: https://wellfound.com/jobs
- Internshala: https://internshala.com/

## Application process
1. Read the full job description.
2. Check location, experience and degree eligibility.
3. Match your actual skills to the requirements.
4. Tailor the resume summary and project bullets truthfully.
5. Apply through the official company or platform page.
6. Record it in `application-tracker.csv`.
7. Follow up politely if appropriate.
8. Review rejection/interview feedback and improve.

## Weekly target
Start with 5 carefully selected applications per working day once you have a credible project foundation. Quality and eligibility matter more than sending hundreds of random applications.

## Resume rules
- One page for a fresher, if possible.
- List only skills you can demonstrate.
- Put projects above generic objective statements.
- Include GitHub links to finished, documented projects.
- Quantify only real results; never invent users, revenue or performance.
- Check degree eligibility. Some roles require B.E./B.Tech; others accept B.Sc.

## Interview practice
- Explain one project aloud every week.
- Solve beginner Python and SQL questions.
- Practise debugging and writing code on a blank editor.
- Prepare clear explanations of database design, authentication, tests and trade-offs.
