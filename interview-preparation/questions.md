# Interview Preparation

## Python — be able to explain and code
1. What is a variable?
2. Difference between list, tuple, set and dictionary?
3. What is mutable vs immutable?
4. What is a function? Parameters vs arguments?
5. What does `return` do?
6. What are exceptions? How does try/except work?
7. What is a module and package?
8. Explain classes, objects, inheritance and composition.
9. What is a virtual environment?
10. What is the difference between `==` and `is`?

## SQL and databases
1. What is a primary key? Foreign key?
2. Difference between INNER JOIN and LEFT JOIN?
3. What is normalization?
4. What is an index and what trade-off does it introduce?
5. What is a transaction?
6. What do COMMIT and ROLLBACK do?
7. Difference between WHERE and HAVING?
8. How do you find duplicate rows?
9. What is a one-to-many relationship?
10. Why use parameterized queries/ORMs?

## Backend and HTTP
1. What is a client-server application?
2. What is an API?
3. What is REST?
4. Explain GET, POST, PUT, PATCH and DELETE.
5. What are common HTTP status codes?
6. What happens from request arrival to response?
7. Authentication vs authorization?
8. What is input validation?
9. What is middleware?
10. Why should secrets be stored in environment variables?

## FastAPI and engineering
1. What does FastAPI do?
2. What is Pydantic used for?
3. What is dependency injection?
4. What is SQLAlchemy?
5. Why use Alembic migrations?
6. What is pytest?
7. Unit test vs integration test?
8. What is Docker?
9. How do you handle errors and log failures?
10. How did you test and deploy your project?

## Project explanation framework
For each project, explain:
- Problem and intended user.
- Main features and API routes.
- Database tables and relationships.
- Authentication and permissions.
- Validation and error handling.
- Tests and what they prove.
- Deployment and setup.
- One difficult bug and how you fixed it.
- One limitation and what you would improve.

Do not memorise answers you cannot explain. Practise with your own code open.
